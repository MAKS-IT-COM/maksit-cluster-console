# Microsoft Store product features

Paste into Partner Center → Store listings → **Product features**.

Short summaries of the product's key features. Displayed as a bulleted list. Up to 20 app features. Each feature is at most 200 characters.

```text
Connect with the kubeconfig you already use. Access follows that identity's permissions.
Choose a context in the catalog to set kubectl's current context.
Browse cluster, nodes, workloads, config, network, storage, namespaces, events, access control, and custom resources.
View, apply, create, and delete resource YAML, including force delete.
Scale and restart workloads, and trigger a CronJob.
Cordon and drain nodes.
Follow pod logs and open a shell in a container.
Save port forwards, restore them on reconnect, and open an active forward in the browser.
Show CPU and memory when the cluster has metrics-server.
Group applications by instance and namespace from standard labels.
Browse, edit, download, and upload files on a persistent volume or claim.
List Helm releases that are already installed in the cluster.
List Dapr components, configurations, subscriptions, resiliency, endpoints, sidecars, and the control plane.
Ask a local Ollama model about the selected resource. Chat can read only.
Keep filters, sort, layout, and port forwards on this PC.
```

The listing description and the other Store text fields are in [description.md](description.md).
